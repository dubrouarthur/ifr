# Navigation data

Generated by `node tools/navdata/build.mjs <ourairports-dir> <FAACIFP18>` — do not edit by hand.

* **OurAirports** (public domain) — airports, runways, frequencies and navaids worldwide.
* **FAA CIFP** (public domain, ARINC 424, AIRAC 2611) — US runways, ILS/LOC, waypoints and instrument
  approach procedures. Minimums are *not* part of CIFP and are derived (training values).

For training only — not for real-world navigation. Re-run the build every AIRAC cycle (28 days).
